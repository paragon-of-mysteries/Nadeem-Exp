Imagine you're writing a school project on your computer. You save it as project.docx. Then you make changes... and more changes... and soon you have:

project_final.docx
project_FINAL2.docx
project_ACTUAL_FINAL.docx 😅

GitHub solves this mess. Instead of saving messy duplicate files, GitHub remembers every single change you've ever made, like a time machine for your work. You can go back to any point in history!

The 3 magic words (simplified)
Repository (Repo) — Think of it like a school bag. Everything for one project lives inside it. Your code, your notes, your images — all in one place, saved online.
Commit — Every time you finish a chunk of work, you "commit" it — like taking a photo of your work at that exact moment. You can always go back to that photo later.
Branch — Imagine you have your project, but you want to try a risky new idea. A branch lets you make a copy to experiment with. If it works, great — you add it back! If not, your original is safe.
